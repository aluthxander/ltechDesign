# 0023 — Inline text dan shared layout

Status: accepted, segmen11, 25 Oktober 2026. Mengembangkan port teks06A tanpa perubahan schema/native version1.0 atau dependency.

Domain tetap tanpa Qt. `SetText` dan `SetTypography` melalui dispatcher, typed validation, revision/dedup/undo yang sama. Port `text_layout(before, planned)` dijalankan sebelum publication dan evaluator layout13. GUI memasang shared Qt reflow pada owner thread; caller domain tanpa port menolak perubahan auto size dengan `text_metrics_required`, bukan mengarang ukuran. Fixed text masih dapat diubah tanpa Qt. Render/validation gagal membatalkan transaksi seluruhnya. Undo mengembalikan snapshot ukuran dan font metadata tanpa mengukur ulang. Transport MCP tetap18/19; ini command lokal yang dapat dipakai caller yang sama.

Satuan serialized yang sudah ada: `font_size` logical px; `letter_spacing` tambahan logical px per glyph advance melalui QFont AbsoluteSpacing; `line_height` `{unit:"multiplier"|"px",value}` adalah jarak baseline. Multiplier mengalikan font_size; px literal. Penggantian unit di Inspector/SetTypography mengonversi value agar jarak baseline tetap. Warna melalui style.fill RGBA, opacity lewat node/group isolation06A. Bukan rich spans31 atau constraints13.

QTextLayout dengan design metrics pada device96dpi menghasilkan shaping, wrapping, UTF16 caret/hit-test dan outline untuk canvas/PNG/PDF. Fixed/auto_height wrap word atau karakter bila kata terlalu panjang; auto_width mempertahankan explicit newline tanpa soft wrap. Real resolver memakai horizontalAdvance (design advance), bukan naturalTextWidth yang memasukkan ink bearing dengan pembulatan backend berbeda. Box adalah clip; overhang glyph di luar box terpotong. Auto width/height mengukur advance dan natural height/jarak baris terakhir, minimum width1, materialisasi ceil1/64px; resize menjaga anchor lokal dalam parent berotasi. Manual width auto_height tetap reflow; resize lainnya beralih fixed. Plain text menormalisasi newline saat input/display; load tidak menulis ulang authored string. Caret/selection/preedit overlay bukan konten atau ekspor.

FontResolver memakai Qt local database; Windows Qt offscreen memuat font lokal via registry Windows karena plugin itu tidak menyediakan native font database. Semua style matching dimuat, dengan batas64 registrasi lokal dan64 embedded per resolver. Font embedded dimuat dari asset bytes sebelum fallback semua family dihitung, termasuk setelah reopen. File path hanya runtime; tidak serialized. Fallback memakai ordered font metadata, script fonts yang terpasang lalu default lokal; ContextFontMerging mempertahankan shaping. Missing font memberi warning di GUI dan render diagnostics tanpa mengganti metadata. Pilihan font Inspector eksplisit membuat/merujuk system Font record; bukan mengubah record shared diam-diam. Font system tidak otomatis embedded dan tidak dijanjikan identik di mesin tanpa font itu. Font berlisensi Abel fixture dipakai untuk bukti embedded portable.

Emoji memakai glyph outline monokrom bila tersedia. Renderer mengeluarkan warning emoji; glyph0/outline emoji yang tidak tersedia mendapat replacement dan warning. Tidak menjanjikan color emoji, seluruh variasi sequence/ZWJ, atau semua script/font. PDF berisi outline, tidak searchable. Resource strict06A tetap menolak glyph hilang; resolver editor menggunakan fallback yang dilaporkan.

Inline editor adalah input buffer QTextEdit tersembunyi untuk Unicode/clipboard/IME, tidak menggambar desain. Input dikirim lewat command setiap perubahan. Ketikan bergabung selama satu edit, jeda1detik/cursor move/paste/cut memisahkan history; Create dan edit tetap langkah terpisah. Ctrl+C/V/X/Delete/Enter bekerja pada teks; Ctrl+Z/Y melalui history dokumen. F2/double click memulai, Esc/Ctrl+Enter/focus keluar menyelesaikan. Revision atau selection eksternal menyelesaikan input lama. Preedit hanya view; commit IME baru menjadi konten. Input/render dibatasi100.000 karakter per box, size/absolute spacing4096px dan text length×size20juta; cache dibatasi. Benchmark dokumen besar/IME hardware tetap acceptance22/performance23.

API diverifikasi pada PySide6/Qt6.10.2, Python3.12.12: [QTextLayout](https://doc.qt.io/qtforpython-6.10/PySide6/QtGui/QTextLayout.html), [QTextLine](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QTextLine.html), [QFont](https://doc.qt.io/qt-6/qfont.html). Dependency pins tidak berubah. Conformance menguji native QApplication dan QGui offscreen, canvas exact PNG, metrics exact, outline backend/PDF edge band1px ≤64/255; interior native/offscreen0 dan PDF≤2/255 untuk dua pembulatan alpha nested. Tidak melonggarkan suite06A.
